# Routelligence

A simple Android starting point for the Routelligence project.

## Included
- Android app module
- Compose-based main screen
- Material 3 theme
- basic project structure
- `MainActivity` and initial UI skeleton

## Run
Open the project in Android Studio and sync Gradle.
